# IThub Events — инструкция по GitHub Pages (публичный сайт)

Это **статическая демонстрация**, а не production-приложение. В корне архива находится готовая папка `docs` с настоящим `index.html`.

## Как обновить существующий репозиторий

1. Распакуйте ZIP.
2. Скопируйте **папку `docs` целиком** в корень репозитория `ithubevents` рядом с существующим README.md (не внутрь другой папки).
3. Откройте Git Bash или CMD в корне проекта и выполните:

```cmd
git add docs
git commit -m "Add IThub Events GitHub Pages site build"
git push origin main
```

4. На GitHub откройте `https://github.com/Oskanov1234/ithubevents/settings/pages`.
5. В **Build and deployment** выберите **Deploy from a branch** → `main` → `/docs` → **Save**.
6. После завершения публикации откройте `https://oskanov1234.github.io/ithubevents/`.

Не выбирайте `/ (root)`: там README.md и Node.js-файлы, которые не являются сборкой для Pages.

## Что работает

Главная, афиши, истории, категории, поиск, карточки мероприятий, светлая/тёмная тема. Данные из первоисточников + опубликованные через локальное демо события.

## Ограничения GitHub Pages

- Нет Node.js, SQLite, реальной авторизации, приёма заявок или общей серверной базы.
- Демо-данные сохраняются в localStorage **данного браузера**, не синхронизируются между устройствами или пользователями.
- Когда оба репозитория опубликованы в одном аккаунте GitHub Pages по адресам `oskanov1234.github.io/ithubevents/` и `oskanov1234.github.io/ithubevents-admin/`, они разделяют origin и localStorage. Поэтому созданное в демо-админке событие видно на публичной демостранице **в том же браузере**. На другом компьютере его не будет.
- Тестовый вход в админку **не защищает данные**; пароль опубликован в исходном JS, как и любой frontend-код.
- Афиши подгружаются из публичного Telegram CDN; при недоступности CDN карточка даст ссылку на исходный пост, но изображение может не отображаться.
- Не вводите реальные персональные данные и не используйте GitHub Pages для рабочей регистрации на мероприятия.

## Как вернуть полноценный сайт

Разверните Node.js + SQLite на подходящем сервере с постоянным хранилищем, HTTPS, защищённой серверной авторизацией и утверждённой политикой данных. Эта статическая сборка — только отдельная презентационная версия.
